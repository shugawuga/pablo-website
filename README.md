# Pablo Valenzuela Portfolio

This repository contains my professional portfolio website created using Quarto for PA 446, Coding for Civic Data Applications.

## Website Structure

The website includes the following pages:

- **Home:** Professional biography, photograph and contact links.
- **Projects:** A showcase of past coursework demonstrating data analysis, programming, visualization and Git/GitHub skills.
- **Fall 2026 Courses:** Current graduate coursework with a Quarto callout feature.
- **Resume:** An embedded professional resume with an option to download the PDF.

## Design Choices

The website uses the Cosmo Quarto theme with additional custom CSS styling. Dark charcoal was selected as the primary heading color to maintain a professional appearance, while purple was used for links, active navigation items and hover effects to provide contrast and visual consistency.

Font sizing uses relative `rem` units to support responsive display across different screen sizes.

## Technical Features

The site demonstrates several Quarto and web-development features, including:

- Quarto website navigation
- Quarto About template
- Bootstrap icons
- Custom CSS styling
- Quarto callout boxe
- Embedded PDF documents
- Downloadable project and resume files
- Git and GitHub version control
- GitHub Pages deployment

## Deployment

The website is rendered to the `docs` directory and published through GitHub Pages from the `main` branch.
